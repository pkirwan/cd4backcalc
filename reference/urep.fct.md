# Function to deal with under-reporting of AIDS diagnoses

Function to deal with under-reporting of AIDS diagnoses

## Usage

``` r
urep.fct(urep, AIDS, urep.flag, nt)
```

## Arguments

- urep:

  Under-reporting factor.

- AIDS:

  A matrix of AIDS diagnoses.

- urep.flag:

  Logical flag indicating if under-reporting is considered.

- nt:

  Total number of time points.

## Value

A matrix of AIDS diagnoses adjusted for under-reporting if applicable.
