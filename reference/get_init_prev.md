# Get initial prevalence matrix to provide to age-dependent model

Get initial prevalence matrix to provide to age-dependent model

## Usage

``` r
get_init_prev(config, exp.prev.arr, start_yr)
```

## Arguments

- config:

  Configuration list.

- exp.prev.arr:

  Expected prevalence array.

- start_yr:

  Starting year.

## Value

Initial prevalence matrix.
