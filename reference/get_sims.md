# Get simulation data for plotting.

Get simulation data for plotting.

## Usage

``` r
get_sims(sim_list, var, var2, plot_years = 29.75)
```

## Arguments

- sim_list:

  A list of simulation results.

- var:

  The variable to extract.

- var2:

  The sub-variable to extract.

- plot_years:

  Number of years in the plot.

## Value

A data frame of simulation results for plotting.
