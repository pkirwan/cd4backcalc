# Generate UK-acquired incidence-ratio patterns

Generate UK-acquired incidence-ratio patterns

## Usage

``` r
generate_ratio_abroad_uk(nquar, pattern, dist = TRUE)
```

## Arguments

- nquar:

  Number of time quarters.

- pattern:

  Pattern for the born-abroad:UK-born ratio of UK-acquired incidence
  ("constant", "increasing").

- dist:

  Logical indicating whether to add normal variation.

## Value

Vector of born-abroad:UK-born UK-acquired incidence ratios.
