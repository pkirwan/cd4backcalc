# Matrix rounding function to preserve totals

Matrix rounding function to preserve totals

## Usage

``` r
round_matrix_preserve(mat, colwise = FALSE, rowwise = FALSE)
```

## Arguments

- mat:

  Numeric matrix to be rounded.

- colwise:

  Logical; if TRUE, round each column separately.

- rowwise:

  Logical; if TRUE, round each row separately.

## Value

Rounded numeric matrix with preserved total.
