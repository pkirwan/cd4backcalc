# Get estimates from HIV model results for plotting.

Get estimates from HIV model results for plotting.

## Usage

``` r
get_estimates(hiv_list, quantity)
```

## Arguments

- hiv_list:

  A list of HIV model results.

- quantity:

  The variable to extract.

## Value

A data frame of model estimates for plotting.
