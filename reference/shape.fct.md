# Function for the shape of incidence curve

This function classifies the shape of the incidence curve in the last
two years as either monotonically increasing, increasing (not
monotonic), decreasing (not monotonic), or monotonically decreasing.

## Usage

``` r
shape.fct(x)
```

## Arguments

- x:

  A numeric vector representing the incidence curve.

## Value

A character string indicating the shape of the incidence curve.
